# UWU 一运模拟器（Godot 4.3）

绝神兵（The Weapon's Refrain）**本体一运「追击之究极幻想」**练习器。
目标是后面扩展到**整个本体阶段**（二运 / 三运）。

> 状态：**M1 骨架**。机制、时间轴、判定、读条已按实测数据实现；Boss 目前是占位方块，等 FBX 模型替换。

---

## 一、怎么跑

1. 装 **Godot 4.3**（Standard 版，不是 .NET 版）：<https://godotengine.org/download>
2. 打开 Godot → `导入` → 选本目录的 `project.godot`
3. 按 `F5` 运行
4. 游戏里按 **空格** 开始一运

**操作**：`WASD` 走位 · `Shift` 疾跑 · `R` 重试本题 · `空格` 开始

### ⚠️ 中文显示成方框？

Godot 默认字体不含中文。解决：把任意中文字体丢进 `assets/fonts/`，例如

```
copy C:\Windows\Fonts\msyh.ttc  assets\fonts\msyh.ttc
```

程序启动时会自动扫描该目录并加载第一个字体。没有这个目录时会在控制台警告，界面显示方框。

## 三、目录结构（照 fru_sim 的分层）

```
project.godot
main/
  Main.tscn            只挂一个脚本，其余全部代码构建
  main.gd              入口：搭环境/场地/玩家/HUD/序列
common/
  yiyun_data.gd        数据加载 + 布局生成 + 安全点求解
  ground_markers/
    aoe_factory.gd     地面预警形状库（线/圆/环）
  player/
    player_controller.gd
ui/
  hud.gd               时间轴 / 状态 / 读条 / 统计
yiyun/
  yiyun_sequence.gd    一运：序列 + 判定（二运三运照这个加）
data/
  yiyun.json           ★ 唯一真值：时间轴 / 判定尺寸 / 坐标 / 标点
assets/
  fonts/               中文字体（自备）
  models/              Boss FBX（自备，见下）
```

**设计要点**：`data/yiyun.json` 是唯一真值，代码不写死数值。
扩到二运/三运时：加 `yiyun/niyun_sequence.gd` + 数据里加一段 timeline，不动现有代码。

## 四、Boss 模型怎么接（M3）

1. 用 **TexTools** 导出四大神的 FBX（找 `Ultima` / `Garuda` / `Ifrit` / `Titan`）
2. 放到：

```
assets/models/
  garuda/garuda.fbx + 贴图
  ifrit/...
  titan/...
  ultima/...
```

3. 我会在 `yiyun_sequence.gd` 的 `_build_boss_placeholders()` 里换成加载 FBX，
   并按目标高度缩放（迦楼罗 7.4 / 伊弗利特 6.2 / 泰坦 8.6 / 神兵 9.8 yalm，见 `data/yiyun.json` 的 `bosses.*.height`）
